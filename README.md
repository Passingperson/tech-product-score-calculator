# 科技产品分值计算器

一个简洁的网页应用，用于评估常见科技产品在技术复杂度、生产成本、便携性和市场均价四个维度的综合得分。数据可随时更新，支持按品类或总分排序。

## 功能特点
- 卡片式展示所有产品，点击展开各维度详细评分
- 两种排序方式：按品类字母序 / 按总分从高到低
- 数据存储在 `data/products.json`，编辑即可更新
- 后端 API 提供数据，前端独立渲染
- 响应式设计，适配移动端

# 启动开发模式（自动重启）
