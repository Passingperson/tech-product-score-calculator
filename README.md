# 📱 科技产品分值计算器

一个交互式科技产品评分工具，支持多维度分值计算、可视化人体视图展示和数量管理。项目基于 Node.js + Express 构建，数据与视图完全解耦。

## ✨ 功能特点

### 📊 分值计算
- 支持 **11 款**主流科技产品（涵盖随身佩戴、手持设备、携带背包三大品类）
- 每个产品从 **4 个维度** 评分（技术复杂度、生产成本、便携性、市场均价），单项满分 10 分
- 总分采用 **等权平均** 计算（满分 10 分），实时显示在卡片上
- 点击卡片可展开查看各维度得分明细

### 🧍 人体视图可视化
- **正面人体**：产品动态映射至对应身体部位（头部、手腕、手掌、口袋），使用 Emoji 标识
- **侧面人体（背包）**：中大型产品自动归类至背包虚线区域，显示 Emoji 和数量
- 多个产品在同一部位时，Emoji 列表合并显示，并标注总数量（不重叠）

### 🔢 数量管理
- 每个产品卡片配备 **“+ / -” 按钮**，可独立调整数量
- 点击卡片主体可快速切换选中状态（数量 0 ↔ 1）
- 数量 > 0 时卡片高亮，并实时同步至人体视图和背包

### 📋 产品卡片
- 按 **品类分组** 显示（随身佩戴 / 手持设备 / 携带背包），每个品类独立成行
- 每个品类内按 **总分从高到低** 排序（固定排序，无下拉选项）
- 卡片名称前显示产品对应的 **Emoji** 图标，直观易识别

### 📈 总分合计
- 人体视图顶部实时显示 **所有选中产品的总分加权和**（单产品总分 × 数量）
- 帮助用户快速了解随身科技产品的综合价值

### 💾 数据管理
- 产品数据存储在 `data/products.json` 中，**编辑即可更新**，无需修改代码
- 支持灵活添加/删除/修改产品及其属性（分值、部位、Emoji 等）
- 数量状态仅保存在前端内存中，刷新页面自动重置
